# PASAR PINTAR ERP

## Enterprise Resource Planning Platform

Version : v0.1.0

Status : Blueprint

---

# Overview

Pasar Pintar ERP adalah platform Enterprise Resource Planning (ERP)
berbasis cloud yang dirancang untuk mendukung berbagai jenis usaha,
mulai dari UMKM, distributor, retail, supermarket, grosir,
hingga perusahaan multi cabang.

Platform ini dibangun menggunakan teknologi modern dengan arsitektur
yang modular, scalable, dan AI Ready.

---

# Vision

Menjadi platform ERP Indonesia yang modern,

dan didukung Artificial Intelligence.

# Coding Standard

Backend menggunakan NestJS.

Database menggunakan Prisma ORM.

Semua API menggunakan REST.

Semua tabel menggunakan soft delete jika memungkinkan.

Semua transaksi menghasilkan audit log.

Semua transaksi menghasilkan activity log.

Semua modul mendukung multi company.

Semua endpoint wajib menggunakan authentication.

Semua endpoint menggunakan permission.
